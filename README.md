# Currency Exchange

Currency Exchange is a web app that uses the [Frankfurter public currency API](https://frankfurter.dev/) to visualize exchange-rate trends between two currencies.

This project is mainly built to showcase a small set of `stdlib` capabilities.

## Installation

To install dependencies, use any Node.js package manager (for example: `npm`, `pnpm`, `yarn`, or `bun`).

### pnpm

```bash
pnpm install
```

### npm

```bash
npm install
```

### yarn

```bash
yarn install
```

### bun

```bash
bun install
```

## Running the app

### pnpm

```bash
pnpm run dev
```

### npm

```bash
npm run dev
```

### yarn

```bash
yarn dev
```

### bun

```bash
bun run dev
```

## stdlib functions used

- `@stdlib/stats-base-mean`
- `@stdlib/stats-base-variance`
- `@stdlib/stats-base-max`
